# ЛЗ 11. Клиентская интерактивность: JavaScript, Fetch/AJAX и обмен данными с сервером

Задача: добавить динамическое поведение интерфейса без полной перезагрузки страницы.
Фреймворк: Django, клиентская часть на чистом JavaScript (`fetch`, `async/await`, без библиотек).

## Что сделано
| Возможность | Как работает |
|---|---|
| Поиск, фильтры, сортировка и страницы слотов без перезагрузки | `fetch` GET, сервер отдаёт HTML-фрагмент, JS заменяет три блока: счётчик, ошибки, список |
| То же для таблицы записей, сортировка кликом по заголовку | тот же механизм, в адресе меняется `?sort=...` через `history.pushState` |
| Удаление записи | окно подтверждения (Bootstrap modal), `fetch` POST, ответ JSON, таблица перезагружается через AJAX |
| Смена статуса (ЛЗ 9) | теперь ещё обновляет число в меню и показывает уведомление |
| Проверка при записи на слот | пока студент вводит ФИО и номер лабораторной, `fetch` GET спрашивает сервер: нет ли дубля |
| Состояния интерфейса | список затемняется и показывается надпись «Загрузка…», ошибка сети: сообщение и кнопка «Повторить», уведомления (toast) |

## Как это устроено
1. **Один адрес, два ответа.** `slot_list_view` и `submission_list_view` смотрят на заголовок `X-Requested-With: XMLHttpRequest`
   (его ставит `request()` в `dynamic.js`). Для обычного запроса возвращается полная страница, для AJAX только фрагмент
   (`_slot_fragment.html`, `_submission_fragment.html`). Оба ответа получают заголовок `Vary: X-Requested-With`,
   чтобы кэш браузера не подменял страницу фрагментом (кнопка «Назад»).
2. **Страница работает и без JavaScript** (прогрессивное улучшение): форма остаётся обычной GET-формой, номера страниц и заголовки колонок обычными ссылками.
3. **Общий слой `request()`** в `dynamic.js`: заголовки, CSRF-токен для POST, понятные ошибки (нет сети, 403, 500), переход на вход, если сессия истекла.
4. **Устаревшие запросы отменяются** (`AbortController`), текст в поиске обрабатывается с задержкой 300 мс (debounce).
5. **Адрес остаётся честным**: `history.pushState` меняет URL, `popstate` обрабатывает «Назад/Вперёд» и возвращает значения в форму.
6. **Безопасность**: права проверяются на сервере (чужую запись удалить нельзя: для студента такой записи нет, ответ 404 в JSON), CSRF-токен передаётся в заголовке `X-CSRFToken`,
   пользовательский текст в JS выводится через `textContent`, HTML-фрагменты приходят из шаблонов Django с автоэкранированием.
   Проверка дубля в браузере только подсказка, окончательно проверяет форма на сервере.
7. AJAX-обновление списка не считается «открытием главной страницы»: счётчик посещений и cookie `last_visit` (ЛЗ 8) не меняются.

## Как показать
1. `python manage.py runserver`, откройте DevTools → вкладка Network.
2. Слоты: введите в поиск «иманбек». Страница не мигает, в Network один запрос `GET /?q=...` с типом fetch, адрес изменился.
3. Включите «Только со свободными местами», смените сортировку, нажмите страницу 2: поиск сохраняется, нажмите «Назад» браузера: значения вернулись.
4. Выключите сеть (Network → Offline) и введите букву: появится «Нет связи с сервером» и «Повторить».
5. Преподаватель, «Все записи»: клик по «Лаба» (▲/▼), фильтр по статусу, смена статуса в строке: уведомление и число в меню меняются.
6. Корзина у записи: окно подтверждения, «Да, удалить»: строка исчезает без перезагрузки, число в меню уменьшается.
7. Студент, запись на слот: введите ФИО и номер уже занятой лабораторной: красная подсказка, затем другой номер: зелёная.
8. `python manage.py test`: все тесты зелёные.
