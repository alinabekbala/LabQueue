# ЛЗ 9. Динамические компоненты и обработка пользовательских событий

Фреймворк: Django. Всё сделано в проекте LabQueue, моделей и миграций новых нет.

## Динамические компоненты (на сервере)

| Приём из лекции | Где в проекте |
|---|---|
| Цикл и условие, `{% for %}…{% empty %}` | `_slot_cards.html` (пустой список слотов) |
| Partial / `{% include %}` | `_slot_card.html` (одна карточка), `_slot_cards.html` (список), `_form_fields.html` |
| Компонент с логикой (`inclusion_tag`) | `top_free_slots` («Больше всего свободных мест»), `nav_badge` (счётчик в меню) — `main/templatetags/slot_tags.py` |
| Свой фильтр шаблона | `ru_places`: 1 место, 2 места, 5 мест |
| Меню и кнопки по роли | `base.html`, `_slot_card.html` (`user.is_staff`), права на сервере (`teacher_required`, `_can_manage`) |
| Списки из БД в формах | `LabSlotForm` (ModelForm: select дисциплин и преподавателей из таблиц) |
| Без N+1 | `select_related` + `annotate(taken_count)`; тест сравнивает число запросов для 1 и 7 слотов |

## Пользовательские события (в браузере), `static/main/js/dynamic.js`

| Событие | Что происходит | Серверная часть |
|---|---|---|
| `setInterval` каждые 10 с (страница записи) | fetch -> JSON, обновляется «Занято: N из M», кнопка блокируется, если мест нет | `slot_seats_view` (GET, JSON) |
| `change` у выпадающего списка статуса (преподаватель) | fetch POST + заголовок `X-CSRFToken`, бейдж меняется без перезагрузки, при ошибке выбор откатывается | `submission_status_view` (только POST, 403 не преподавателю, 400 на неверный статус) |
| `input` у поля «Ссылка на GitHub» | мгновенная подсказка; итоговая проверка остаётся на сервере (`clean_github_url`) | `forms.py` |

## Безопасность
* Данные от пользователя в JS выводятся через `textContent`, а не `innerHTML`.
* Шаблоны Django экранируют вывод автоматически (`|safe` для пользовательских данных не используется).
* Скрыть кнопку недостаточно: права проверяются на сервере (403).
* CSRF-токен передаётся в заголовке для POST-запроса из JavaScript.

## Как показать
1. Войти студентом: на главной блок «Больше всего свободных мест», в меню красный счётчик у «Мои записи».
2. Открыть запись на слот: ввести неверную ссылку (красная подсказка), затем github.com/...; число мест обновляется само.
3. Войти преподавателем: «Все записи» — поменять статус в списке, бейдж меняется без перезагрузки, после F5 статус сохранён.
4. `python manage.py test` — 60 тестов (24 новых в `main/test_dynamic.py`).
