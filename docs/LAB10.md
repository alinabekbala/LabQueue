# ЛЗ 10. Отображение, поиск, фильтрация, сортировка и пагинация данных

Фреймворк: Django. Реализовано в проекте LabQueue для двух списков: слоты (карточки, 6 на страницу)
и записи студентов (таблица, 10 на страницу).

## Соответствие лекции 10

| Тема лекции | Где в проекте |
|---|---|
| Вывод набора: таблица и цикл, `{% empty %}` | `submission_list.html`, `_slot_cards.html` |
| Параметры запроса: форма GET, `request.GET` | `_slot_filters.html`, `_submission_filters.html`; значения проверяют формы в `main/filters.py` |
| Поиск: `icontains`, `Q` по нескольким полям | `search_q()` в `filters.py`: каждое слово должно найтись хотя бы в одном поле |
| Отложенное выполнение QuerySet | условия добавляются по одному, SQL выполняется один раз; нет `list()` до фильтров |
| Фильтрация по категории и диапазону, только если задано | `apply_filters()`: дисциплина, преподаватель, статус, номер лабораторной, `date_time__date__gte/lte`, «только свободные» |
| Безопасная сортировка | словарь `SORTS` (белый список); пользователь передаёт ключ, поле выбирает сервер; несколько ключей и `pk` для стабильного порядка |
| Пагинация | `Paginator` + `get_page()` (неверный номер не ломает страницу); размеры 6 и 10 заданы на сервере |
| Ссылки страниц сохраняют параметры | теги `url_replace`, `pagination`, `sort_th` в `templatetags/slot_tags.py` |
| Подсчёт | `paginator.count` (отдельный `COUNT`), «Показано X–Y из N» |
| Качество и производительность | `select_related`, `annotate` (без N+1); индексы по `date_time`, `status`, `lab_number` (миграция `0002_list_indexes`) |

## Дополнительно
* Права проверяются до поиска и фильтров: студент видит только свои записи.
* Выбранная дисциплина на главной по-прежнему запоминается в сессии (ЛЗ 8).
* SQLite не различает регистр кириллицы в `LIKE`, поэтому в `main/apps.py` подменена функция `like`; на PostgreSQL это не нужно.
* Индекс не ускоряет `icontains` (`LIKE '%текст%'`), он помогает сортировке, диапазонам и точным условиям.

## Как показать
1. `python manage.py migrate`, затем `python manage.py seed_demo --many` и `python manage.py runserver`.
2. Слоты: поиск «иманбек», «Только со свободными местами», сортировка, страница 2 (поиск сохранён в адресе).
3. Адрес с мусором `/?subject=abc&sort=hack&page=zz`: ошибки нет, показано сообщение.
4. Записи (преподаватель): клик по заголовку «Лаба» дважды, фильтр по статусу, пагинация. Студент видит только свои записи.
5. SQL запроса: `python manage.py shell -c "from main.models import LabSlot; print(LabSlot.objects.filter(subject__title__icontains='веб').order_by('date_time','pk')[:6].query)"`.
6. `python manage.py test` — 99 тестов (39 по спискам).
